INVITACIÓN WEB — MAGDALENA & BARTOLOMÉ (VERSIÓN LIMPIA)

Estructura reconstruida en código puro (HTML/CSS) basada en tus bocetos, pero:
- Más limpia y rápida (sin depender de imágenes pesadas de fondo).
- Sin la foto de la pareja.
- Con un color de fondo mucho más blanco/roto, elegante y no amarillo.
- Totalmente responsiva y con textos seleccionables.
- Todos los botones funcionan directamente en el código.

Instrucciones para GitHub Pages:
1. Descomprime este archivo ZIP.
2. Sube únicamente estos 3 archivos (index.html, style.css y script.js) a tu repositorio.
3. ¡No necesitas subir ninguna de las imágenes de los bocetos! El diseño se genera automáticamente.
